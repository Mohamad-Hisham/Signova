For each actual source, Basil's controlled record must capture source_id, exact release/link, acquisition date, responsible contact/custodian, byte hashes, license evidence, approved training/evaluation/distribution/demo uses, restrictions, consent/rights reference, approval status, verified label/variety review, available signer/session/parent grouping, quality/coverage findings and retention/withdrawal rules. Personal/contact/consent evidence belongs in restricted storage, not this public index.

`data/source_register/` holds reviewed safe source metadata schemas/references only. Local originals and restricted records belong in approved external storage or ignored payload layers. `docs/datasets/` explains policy; it does not duplicate a populated registry. Until an audited release exists, no dataset sizes, class counts or model feasibility are asserted.
