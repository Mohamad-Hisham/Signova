## Future acceptance coverage

Vitest and React Testing Library should verify independent revision/state merges, duplicate delivery, protected drafts, retained command identities, stale streams, camera cleanup/late permission, ack matching, denied clipboard/storage and safe accessible states. Tests use full schema-valid synthetic objects, not unsafe casts or real user sessions. No tests/dependencies are added or run now; see the shared integration checklist for scenarios.
